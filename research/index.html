Volumetric video

DynamicPointCloudSubjectiveTest a dynamic point cloud (Volumetric video) subjective test environment

a Unity- based environment where the point cloud video is imported and rendered in real-time by utilizing Miniply . The environment allows real-time import of point cloud frames written under binary little-endian and binary big-endian with a consistent framerate of 30FPS. Moreover, to render the point cloud videos on VR Headset, a point shader that utilizes Unity Single-Pass Instanced rendering is implement.

software unity c# pointcloud
PCPREP a point cloud preparation tool

A robust set of tools for preprocessing and analyzing point cloud data, with a focus on modularity, scalability, and ease of integration.

library software c c++ pointcloud
PCC a point cloud compression tool

A lightweight, modular C/C++ library for real-time point cloud compression and streaming, meant for fast decoding for low-latency streaming and playback, supports multiple codecs, minimal dependencies, easy to integrate.
